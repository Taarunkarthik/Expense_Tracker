# Expense Tracker

A full-stack expense tracker for monthly budgeting and expense maintenance.

## Planned stack
- Web: React + Vite + TypeScript
- API: Express + TypeScript
- Database: PostgreSQL with Prisma
- Auth: Email/password login with JWT

## Scripts
- `npm run dev:api` - start the API
- `npm run dev:web` - start the web app
- `npm run build` - build both apps
- `npm run lint` - lint both apps
- `npm run typecheck` - typecheck both apps

## Overview

Basic expense tracking for people who want to manage monthly spending, budgets, and recurring bills.
